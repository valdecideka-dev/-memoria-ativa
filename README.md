# Memória Ativa

Plataforma para gestão e organização de memória ativa.

## Instalação

```bash
npm install
```

## Configuração

Crie um arquivo `.env` baseado no `.env.example`:

```bash
cp .env.example .env
```

Preencha as variáveis de ambiente necessárias:
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`
- Outras conforme necessário

## Desenvolvimento

```bash
npm run dev
```

## Deploy

O projeto está configurado para ser deployado no Vercel.

```bash
npm run build
```
